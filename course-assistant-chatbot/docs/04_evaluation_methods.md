# Evaluation Methods in HCI

HCI evaluation methods split into two broad families.

Formative evaluation happens during design, to find problems and improve the
product. Summative evaluation happens at the end, to measure how good the
finished product is. A quick way to remember it: formative forms the design,
summative sums it up.

Usability testing observes real users performing tasks with the system. In
the think-aloud protocol, participants verbalize their thoughts while working
("I'm clicking this because..."), which reveals why problems occur, not just
that they occur. Typical usability metrics include task completion rate, time
on task, error rate, and subjective satisfaction (often measured with the
System Usability Scale, SUS).

Heuristic evaluation is an inspection method: three to five evaluators
independently check the interface against usability heuristics (usually
Nielsen's ten) and merge their findings. It is cheap and fast but finds
different problems than user testing, so the two complement each other.

Other methods include cognitive walkthroughs (stepping through a task asking
whether a new user would know what to do at each step), A/B testing
(comparing two versions with live traffic), and analytics-based evaluation.
For conversational systems like our chatbot, evaluation typically combines
answer accuracy on a fixed question set with response time and user
satisfaction.
