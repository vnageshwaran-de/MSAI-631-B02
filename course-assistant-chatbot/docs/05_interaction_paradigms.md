# Interaction Paradigms: From Punch Cards to Conversation

Human-computer interaction has moved through several major paradigms.

In the batch era, users interacted through punch cards and printouts, with
turnaround times of hours. Command-line interfaces made interaction
immediate but required memorizing commands, prioritizing recall over
recognition.

The graphical user interface (GUI) introduced the WIMP paradigm: Windows,
Icons, Menus, and Pointer. Developed at Xerox PARC and popularized by the
Apple Macintosh in 1984, WIMP made options visible and let users recognize
rather than recall, which opened computing to non-specialists.

Touch interfaces on smartphones brought direct manipulation to the
mainstream: users touch the objects of interest directly rather than
steering a pointer. Voice and conversational interfaces (Siri, Alexa,
chatbots) represent the newest widely adopted paradigm, where the user
states an intent in natural language and the system figures out the action.

Virtual and augmented reality extend interaction into 3D space. Each
paradigm shift lowered a barrier: batch to CLI removed the wait, CLI to GUI
removed memorization, GUI to touch removed the pointer, and conversation
removes the need to learn an interface at all -- if the system understands
you, which is exactly the challenge our project explores.
